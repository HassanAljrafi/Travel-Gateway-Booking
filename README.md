# ✈️ بوابة المكان المناسب لرحلتك (Travel-Gateway-Booking)
موقع ويب تفاعلي مبني بلغة HTML لاستعراض الوجهات السياحية الدولية وتفاصيل الرحلات وفئات التذاكر والأسعار ومواعيد الانطلاق بطريقة منظمة وسهلة الاستخدام.

---

## ✨ المميزات الرئيسية
* بوابة وجهات متعددة: استعراض وجهات سياحية مختارة مثل دبي (الإمارات)، تركيا، سويسرا، واليابان مع نبذة تعريفية لكل وجهة وصور ومعارض مرئية.
* **صفحة حجز التذاكر (booking.html):** عرض فئات التذاكر (VIP، الدرجة الأولى، المقاعد العادية) مع وصف المقاعد والخدمات والأسعار بالدولار.
* جدول الرحلات والصالات: توضيح الوجهات، صالات الانتظار (A، B، C، D)، ومواعيد الرحلات اليومية.
* نموذج بيانات المسافر: حقول لإدخال بيانات الحجز مثل الاسم الرباعي والعمر.
